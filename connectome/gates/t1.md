# T1 notes

Date: 2026-08-29. Mesh: `pnpm dev` from `connectome/`. Recheck: `node scripts/t1-check.mjs`.

## T1.1 Origin-routed invoke

- `PEER_KEYS` is `{ sessionId: { publicKey, origin, helloAt } }`.
- `HubClient.invoke` seals to `latestPeerId(...)` (most recently HELLOed of that origin), not the first peer.
- Unit: two Ledger sessions, the later `helloAt` wins; missing origin → `null` → `APP_UNAVAILABLE`.
- Three-app write (create-invoice only in Ledger, list-entries only in Tick) is the Gate A/B demo on this routing.

## T1.2 close-surface

- Surface socket carries `host` (query + HELLO). HubDO stores it on the surface session.
- `close-surface` from a surface-role session is forwarded to the most recently HELLOed spoke of that host.
- Check: surface WS with `host=http://localhost:8787` → CRM WS receives `{ t: "close-surface" }`.

## T1.3 Mapper values-guard

- `POST /map` with `{ path, type, value }` → 400, no `mapping` in the body.

## T1.4 HubDO never parses tool args

- `hub-do.js` has no `args` identifier except the audit comment “Never args, never results.”
- `M.SEALED` forwards `msg.sealed` unread.

## T1.5 Join door

- Unlisted `Origin` POST `/api/pause` → 403.
- No-`Origin` POST `/api/pause` → 403.
- Surface `Origin` POST `/api/pause` → 200, `Access-Control-Allow-Origin` is the surface, not `*`.
- Unlisted `Origin` GET `/api/grants` → 403. No-`Origin` GET allowed.
- Unlisted / missing `Origin` on `/hub` → 403.
- CRM `Origin` + `?origin=http://localhost:8788&role=surface` still registers **as 8787**. Query origin/role are not identity. Name remains a poster.

## T1.6 Surface-only invoke

- Spoke-to-spoke `SEALED` (CRM session → Ledger session, including when the CRM socket claimed `?role=surface`) → `RESULT` `APP_UNAVAILABLE`, no forward.
- Unlisted origin cannot open `/hub`, so cannot cause a write.
- PageBridge: edge-path `handleInvoke` only if `PEER_KEYS` origin of `msg.from` is the configured surface origin. Plaintext `INVOKE` ignored on the edge path.
- Threat note updated to match the edge path.
